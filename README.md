# 3er Bot Team - Autonom

## Was machen sie?
- AutoBot1 = Lumberjack (Holz)
- AutoBot2 = Miner (Stein + Erze)
- AutoBot3 = Hunter + Lager-Manager (Essen + Kisten)

Sie teilen sich:
- Ein gemeinsames Lager (erste Kiste die sie finden)
- Einen Lock damit nicht 2 gleichzeitig die Kiste öffnen
- Globalen State (wie viel Holz/Stein/Essen da ist)

Ohne Anweisung! Sie laufen komplett alleine.

## Aternos Setup
BOT_COUNT=3 braucht 3 Slots auf Aternos! Stell auf aternos.org unter Spieler -> max 5 oder mehr.

Server muss an sein.

## Status
Auf Render: https://dein-service.onrender.com/
Zeigt alle 3 Bots, ihre Tasks und das Lager.

## Befehle optional
Die Bots hören nicht auf Befehle, aber sie loggen Chat.
